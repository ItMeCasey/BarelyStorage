# BarelyStorage

A physical, industrial storage and auto-crafting network for Minecraft on Forge and NeoForge (26.1.2, 26.2, 26.3). Server racks, drive cartridges, storage buses, pattern terminals and crafting blades, powered by Forge Energy.

Work in progress. See the wiki at https://itmecasey.com/wiki/barelystorage/ once it is published.
